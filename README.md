# Project 11 – Infra Changes with Branching Policy

## Objective
Practice Git branching strategy and infrastructure change management using Terraform.

## Infrastructure
- AWS S3 bucket
- AWS Provider
- Region: ap-south-1

## Workflow
1. Maintain the main branch.
2. Create a feature branch.
3. Make infrastructure changes.
4. Validate Terraform configuration.
5. Raise a Pull Request.
6. Review and merge the Pull Request.

Note: Terraform configuration is validated only. No AWS resources are deployed.
